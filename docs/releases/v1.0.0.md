# MotionLab v1.0.0

MotionLab v1.0.0 is the first public product release of the local-first video mechanics workspace.

## Highlights

- Import an ordinary local video and move from calibration through editable tracking to timestamp-based motion analysis.
- Measure with frame-associated annotations, planar world coordinates, multi-object tracks, synchronized graphs, smoothing, and simple motion-model fits.
- Review residual diagnostics and conservative potential-deviation cues without automatically discarding or changing observations.
- Use experimental local Assisted Tracking as a review-and-reseed productivity aid while manual correction remains first-class.
- Save versioned projects, relink source video locally, export scientific CSV/JSON/SVG data, and build printable or standalone HTML experiment reports.
- Learn the workflow through first-run onboarding, contextual guidance, keyboard help, examples, and a bundled constant-speed sample.

## Privacy

MotionLab requires no account or backend. Selected videos are decoded and processed locally in the browser and are not embedded in `.motionlab` projects or standalone reports.

## Scientific scope

Calibration is a uniform single-plane scale and does not correct perspective or depth. Frame stepping is approximate, tracking requires review, numerical differentiation can amplify noise, and fitted models describe rather than prove the selected motion. See the README for the complete scientific limitations.

## Compatibility

The application version is `1.0.0`. `.motionlab` project format remains version 1 and stays compatible with validated projects created during earlier development phases, including projects without Phase 12 report preferences.
