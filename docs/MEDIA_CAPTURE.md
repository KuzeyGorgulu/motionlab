# MotionLab Release Media

All public screenshots and demos must show the working application. Do not substitute mockups or generated UI imagery.

## Recreate v1 screenshots

The repository includes a legally safe synthetic constant-speed video and a separate normal version-1 project. Start MotionLab, then run the Playwright capture script:

```bash
npm run dev -- --host 127.0.0.1 --port 4173
node scripts/capture-release-media.mjs
```

Set `MOTIONLAB_CAPTURE_URL` if the app runs at another local URL. The script captures the real import screen, tracking workspace, position graph, model-fit residual view, and experiment report into `docs/assets/` at 1440 × 960. Review every image after capture for clipping, unexpected local filenames, stale version text, and misleading states.

The bundled sample media is generated by `node scripts/generate-sample-video.mjs`. It is an original synthetic graphic created for MotionLab and may be redistributed with the repository. The video remains separate from `constant-speed.motionlab`, preserving normal project semantics.

`docs/assets/assisted-tracking-demo.gif` is the existing genuine product demo. Re-record it only from a real MotionLab session and keep the experimental label/accepted-suggestion review context visible.

## Short demo video checklist

Target 30–60 seconds and record one consistent, real experiment:

1. Open the import screen and briefly show the local-first message.
2. Import a video or open the bundled sample.
3. Show the calibration scale/origin and a tracked point.
4. Step the video and add or review confirmed track observations.
5. Open Position/Velocity analysis and select a suitable model.
6. Switch to residual diagnostics and seek one observation.
7. Open the Report workspace and show Print / Save PDF plus standalone HTML export.
8. End on the MotionLab v1.0.0 About view or project README URL.

Record at 1440p or 1080p with readable UI scale. Do not imply that calibration removes perspective, that tracking is infallible, that smoothing reveals ground truth, or that a fitted model proves a law. Place an approved final recording at `docs/assets/motionlab-v1-demo.mp4` and add it to the README only after human review and browser playback verification.
